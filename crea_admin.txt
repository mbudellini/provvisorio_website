Per accedere alla dashboard admin, ecco i passaggi da seguire:

## 1. Configura il file .env del frontend admin

Devi creare il file `.env` nella cartella `frontend/admin/` (basato sull'esempio):

```bash
# frontend/admin/.env
VITE_API_URL=http://localhost:4444
```

Assicurati che l'URL punti al tuo backend (in questo caso `localhost:4444`).

## 2. Crea l'account admin (se non esiste già)

Dalla cartella `provvisorio_backend/`, esegui:

```bash
# Per creare admin con credenziali di default (admin / admin123)
npm run seed-admin

# Oppure con credenziali personalizzate
npm run seed-admin -- tuo_username tua_password
```

## 3. Avvia il backend (se non è già in esecuzione)

```bash
cd provvisorio_backend
npm start
# oppure in development
npm run dev
```

## 4. Avvia il frontend admin

In un nuovo terminale:

```bash
cd frontend/admin
npm install  # se non l'hai fatto ancora
npm run dev
```

## 5. Accedi alla pagina

Vai su `http://localhost:5173` (o l'URL che Vite ti mostra nel terminale) e:

1. Inserisci username e password dell'admin
2. Clicca su Login
3. Sarai reindirizzato alla Dashboard

Da lì puoi navigare usando il menu laterale:

- 📊 __Dashboard__ - Overview
- 📂 __Categorie__ - Gestisci categorie (Pantaloni, T-Shirt, ecc.)
- 📁 __Collezioni__ - Gestisci collezioni
- 👕 __Prodotti__ - Gestisci prodotti

Vuoi che ti aiuti con qualcuno di questi passaggi? Posso controllare se il backend è in esecuzione o verificare la configurazione.
